# Progetto di Indagine Statistica in R

Questo repository contiene un software sviluppato in linguaggio **R** finalizzato alla conduzione di un'indagine statistica descrittiva (univariata e bivariata) su dati personalizzabili. Il codice è strutturato per essere flessibile ed eseguibile in tempo reale, consentendo di modificare i dati di input originari direttamente durante la discussione per aggiornare istantaneamente i risultati.

## 📋 Funzionalità principali

Il software esegue un'analisi statistica completa suddivisa nelle seguenti macro-aree e funzioni:

### 1. Analisi Univariata
* **Tabella delle frequenze:** Calcolo automatico di frequenze assolute, assolute cumulative, relative e relative cumulative.
* **Rappresentazioni grafiche:** Generazione dinamica di grafici ad aste, a linee, a barre, istogrammi o grafici a torta.
* **Indici di posizione:** Calcolo di media campionaria, mediana campionaria e moda campionaria.
* **Indici di variabilità:** Calcolo di varianza campionaria, deviazione standard campionaria, scarto medio assoluto, ampiezza del campo di variazione (range) e coefficiente di variazione.
* **Indici di forma:** Calcolo dell'indice di asimmetria (skewness) e dell'indice di curtosi (kurtosis).
* **Quartili e Box Plot:** Individuazione dei quartili della distribuzione e visualizzazione del box plot per l'analisi della dispersione e degli outlier.

### 2. Analisi Bivariata
* **Diagramma a dispersione:** Generazione dello scatter plot per analizzare visivamente la relazione tra due variabili.
* **Coefficiente di correlazione campionario:** Calcolo dell'indice di correlazione per quantificare la forza e la direzione del legame lineare tra le variabili.
